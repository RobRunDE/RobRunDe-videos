# RobRunDe-videos

Automatische ROB-RUN-Shorts für TikTok @robrun_de.

- `raw/` – Gameplay-Rohmaterial (Archiv)
- `videos/` – fertige Videos (Buffer lädt sie von hier)
- `plan/` – Wochenpläne, Video-Specs, Post-Log
- `knowledge/` – geprüfte Fakten & Trends
- `index/` – Clip-Archiv mit Tags
- `pipeline/` – Werkzeuge (Stimme, Schnitt, Animation)

Anleitung für den Agenten: `CLAUDE.md`.
